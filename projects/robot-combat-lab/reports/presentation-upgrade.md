# 三方案观看增强：数值、声音与三维画面

这次优化只改观看层。原始 G1/NCP 轨迹、动作、接触和判定均保留；原视频也保留为 battle.mp4。新版本为 presentation.mp4。

## G1 与 NCP

- 采用更近的摄像机、更清楚的外壳/关节材质、地面光照和阴影。G1 保留源 URDF 的真实外形网格；NCP 保留其数字人本体，不冒充实体机器人。
- HUD 显示倾角、根部高度、关节力矩/模型限幅比例、速度、正机械功、最近33ms接触峰值、累计冲量和3秒力曲线。
- 接触段以3N为提示门限、80ms无接触间隔分段。分段数不是命中次数，也不判伤害。当前接触段峰值只使用截至当前时刻的记录。
- 合成接触提示音由真实接触段触发；音量只作提示映射，不代表真实声压或录音。
- 默认30fps、1×回放；页面允许0.5×/0.25×慢放，并为每个方案提供独立音效开关。浏览器默认静音。

## B-Human

- 自编译原生 SimRobot 增加可选的帧缓冲和只读比赛数据导出。录制开关由本地 capture-request.json 控制；到期停止采样，不改机器人控制或裁判规则。
- 多重采样窗口通过 Qt 解析后读取。早期黑帧探针保留为失败诊断，没有作为有效录像发布。
- 最终录像按原生 MuJoCo 物理时钟采样，每至少16个2ms物理步采一帧；每帧保留墙钟和物理时钟。回放按物理时钟选择实际采集帧，不用插值制造动作，也不把录制开销当成慢动作。
- 比分、阶段、剩余时间和球位置来自原生裁判/模型数据。球速由球位置差分除以仿真时间差计算；非PLAYING、阶段/比分变化、异常采样间隔和位置跳变显示未知。
- 球速提示音根据有效球速产生；哨声/得分提示仅在实际阶段/比分变化时触发。全部为合成数据提示，不是麦克风录音。

## 真实性边界

工程模型的材质、光照和摄像机已改善，但仍是 MuJoCo/SimRobot 渲染，不是照片级实机录像。没有虚构血量、损坏阈值、命中得分或胜负。NCP 的关节限幅属于数字人模型参数，不能当成某款实体机器人的硬件规格。

`presentation.json`记录来源哈希、参数和事件；原始档案与新视频均有manifest。测试检查接触冲量重建、物理参数保持不变、音轨非空、足球帧非黑以及实际采样时钟。

## 本次验收

12项测试通过。三个视频均为H.264＋AAC，编码30fps；G1/NCP各约20秒，足球约29.95秒仿真时间。足球保留801张实际画面，按物理时钟约26.71帧/秒采集，墙钟录制约66秒；视频不按录制开销减速。测试确认接触冲量可重建，物理参数未变，原始轨迹/动作哈希一致，足球帧非黑且球确有运动，裁判事件仅来自视频覆盖时段。浏览器已验证各音效开关、0.5×和0.25×慢放、三个视频解码正常。
